# MathBridge - Real-World Math Connections

MathBridge is an interactive educational web app designed to show students how classroom mathematics directly connects to their real-world interests and hobbies.

## 🚀 Features
- **Personalized Scenarios:** Connects topics like Algebra, Trigonometry, and Calculus to hobbies like Gaming, Cooking, and Sports.
- **AI-Powered Problem Generator:** Creates dynamic practice problems tailored to student inputs.
- **Step-by-Step Solutions:** Explains complex concepts with simple, structured breakdowns.

## 🛠️ Built With
- **Frontend:** React / HTML / Tailwind CSS (Designed with Google Stitch)
- **Deployment:** Vercel
